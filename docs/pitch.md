# Project Pitch

Basically marktext but with an ai conversation panel

You make plans and then chat with the LLM about those plans.

Specific plugins like the LLM having api access will let you turn this into a redmine or jira project manager, or able to give ad hoc reporting on a todo app, etc., but the goal is to keep the ai's capabilities narrow enough for it to be consistently functional. 

- reading and writing files in a markdown wiki

- maybe a plugin to give it API access



That's it. An AI assistant that you can kind of talk to about the projects you're working on, just hang out in your plans.
